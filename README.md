## Development server

**Note**: The development server now uses the modern application builder with Vite for faster hot module replacement and build times.

## Code scaffolding

Run `ng generate component component-name` to generate a new component. You can also use `ng generate directive|pipe|service|class|guard|interface|enum|module`.

**Modern Options**:
- Use `--standalone` flag for standalone components (recommended)
- Templates will use modern `@if`, `@for` control flow syntax by default
